# Проверка перед выпуском

## Игра

- [ ] Все 30 уровней имеют корректное решение; `npm test` проходит.
- [ ] На настоящем телефоне работают выбор, перетаскивание, поворот, отмена и повтор уровня.
- [ ] Нет перекрытий интерфейса на небольшом экране и при увеличенном системном шрифте.
- [ ] Прогресс сохраняется после закрытия приложения; сброс работает только после подтверждения.
- [ ] Основные уровни запускаются без сети.

## Реклама

В первом release 1.0.0 используется `YANDEX_ADS_DISABLED=true`. Проверки показа относятся к debug и будущему выпуску с рекламой.

- [ ] Проверена тестовая реклама на Android, включая закрытие, ошибку загрузки, отсутствие сети и возвращение в игру.
- [ ] Награда выдаётся только по событию подтверждённого вознаграждения; одно объявление не выдаёт награду дважды.
- [ ] Закрытие рекламы без награды сохраняет обычный игровой прогресс.
- [ ] В release указан собственный действующий rewarded-блок и приложение прошло модерацию РСЯ; либо реклама явно отключена через `YANDEX_ADS_DISABLED=true` и карточка отражает этот режим.
- [ ] В первой версии без рекламы нет загрузки объявлений; подсказка и удвоение монет выдаются бесплатно, как написано в интерфейсе.
- [ ] Перед инициализацией SDK проверены применимые настройки приватности и соответствие выбранной аудитории.

## Сборка и RuStore

- [ ] Проверен пакет `ru.dachatrunk.game`; подпись принадлежит владельцу проекта и сохранена в резервной копии.
- [ ] Загружается подписанный release APK, не debug-артефакт из Actions.
- [ ] Для обновления увеличен `versionCode` и сохранена прежняя подпись.
- [ ] В Консоли заполнены описание, контакт, возрастная категория, рекламные SDK и декларация данных по итоговому APK.
- [ ] Загружены иконка и не менее трёх реальных скриншотов.
- [ ] Страница `public/privacy.html` доступна по опубликованной ссылке; оператор Соболь Александр и контакт GitHub Issues соответствуют карточке.
- [ ] Приложение создано в RuStore; для SDK отзывов настроены package и сертификат, сценарий проверен после публикации.
- [ ] При использовании API проверен результат загрузки; модерация и публикация выполняются отдельно.

## После выпуска

Записать номер версии, отпечаток сертификата, URL карточки, использованный ID рекламы и результат проверки на устройстве. Не заносить пароли, приватные ключи и токены в репозиторий или отчёт.

Приложение `2063777822`, версия-черновик `2064915117`: загружены подписанный APK, иконка, три реальных скриншота и описание. Публикация выбрана вручную; на модерацию версия не отправлена.

В декларации предварительно отмечены имя автора, другие действия (оценка) и другой пользовательский контент (текст отзыва) для необязательной функции RuStore Review. Это классификация по назначению функции, а не подтверждённая полная матрица данных SDK. Перед модерацией нужно окончательно сверить перечень данных Review SDK, включая возможные технические данные. Отсутствие рекламы не означает отсутствие всех сетевых функций. Автообнаруженные Yandex Mobile Ads и Google Mobile Ads оставлены как есть: второе определяется транзитивными библиотеками AppMetrica/Google identifiers; полноценный AdMob не подключён.
