# Проверка выпуска 1.0.0

Дата: 28 октября 2026 года. Пакет: `ru.dachatrunk.game`, versionCode 1. Реклама в подписанном выпуске отключена.

- 52 проверки движка и сохранений: все 30 уровней решаемы, наложения и выход за границы отклоняются, подсказки исправляют раскладку, повторное прохождение не выдаёт основную награду повторно.
- 5 проверок инструмента загрузки RuStore: подпись запроса, загрузка только в существующий черновик, безопасная обработка ошибок.
- Браузер: прохождение первого уровня, перетаскивание, поворот, отмена, подсказки, бесплатный бонус, покупка цвета и восстановление сохранений; мобильная ширина 390 px.
- Android: Gradle assembleRelease/bundleRelease, lintDebug и lintVitalRelease; проверка подписи APK v2, установка и запуск подписанного APK в эмуляторе. Проверены системная кнопка «Назад» и загрузка локальных игровых файлов.
- Отдельная debug-сборка: реальная демонстрационная реклама Yandex Mobile Ads; одно событие награды после завершения просмотра. В release этот режим отключён.
- GitHub Actions: сборка и публикация Pages, сборка debug APK проходят. Игровая страница и политика возвращают HTTP 200.
- Реальные снимки подписанной Android-сборки: `store-assets/`, PNG 1080×1920.

## Границы проверки

Проверка на личном физическом телефоне владельца ещё не выполнена. До публикации рекламного обновления нужны настоящий блок РСЯ и проверка сведений о данных для всех активных SDK. SDK оценок корректно обрабатывает отсутствие доступного RuStore; успешный отзыв из опубликованной версии пока не проверен. Принятие APK в черновик не означает прохождение модерации магазина.
