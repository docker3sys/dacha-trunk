# Политика конфиденциальности
«Багажник на дачу» · редакция от 28 октября 2026 года

Политика применяется к браузерной игре и первому выпуску Android 1.0.0 с отключённой рекламой, пакет `ru.dachatrunk.game`. В этих версиях реклама не показывается, игровые бонусы бесплатные.


## Оператор и связь
Оператор игры — **Соболь Александр**. Вопросы о данных и работе игры можно направить через [GitHub Issues](https://github.com/docker3sys/dacha-trunk/issues). Обращения там публичны: не прикладывайте документы, пароли и другие конфиденциальные сведения.


## Данные игры на устройстве
Для игры не нужны регистрация, имя, телефон или электронная почта. Пройденные уровни, звёзды, текущая раскладка вещей, монеты, подсказки, выбранный цвет машины и настройки звука сохраняются локально на устройстве. Также сохраняется отметка о том, предлагалась ли оценка игры. Эти сведения нужны для продолжения игры и не отправляются на сервер разработчика; облачная синхронизация не предусмотрена.

В браузере используется локальное хранилище сайта, в Android — локальное хранилище приложения. Данные остаются до очистки хранилища сайта или приложения; удаление Android-приложения также удаляет его локальные данные. Смена устройства не переносит прогресс автоматически.


## Браузерная версия
Браузерная игра не подключает рекламные сети и счётчики аналитики. Шрифт и игровые материалы загружаются с того же сайта. При посещении страницы хостинг GitHub Pages может обрабатывать IP-адрес и технические сведения о запросе по [политике GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).


## Первый выпуск Android без рекламы
В Android 1.0.0 показ рекламы отключён. Игра не запрашивает рекламные объявления и не инициализирует Yandex Mobile Ads для их показа. Подсказки и бонусы предоставляются бесплатно. В составе приложения присутствуют Yandex Mobile Ads SDK и его технические зависимости, включая AppMetrica, для последующей настройки рекламной версии. Наличие этих библиотек само по себе не означает, что первый выпуск показывает рекламу.

Игровые функции не требуют доступа к контактам, камере, микрофону или точной геолокации. В манифесте приложения удалено разрешение на рекламный идентификатор `AD_ID`.


## Если реклама будет включена в обновлении
Этот раздел описывает подготовленную интеграцию; к показам в первой версии 1.0.0 он не применяется. До выпуска обновления с рекламой политика и сведения в магазине будут актуализированы.

В версии с включённой рекламой просмотр видео за подсказку или игровой бонус будет добровольным. При запросе рекламы SDK Яндекса может обрабатывать технические сведения об устройстве, сетевом соединении, взаимодействии с объявлением и диагностике для показа, измерения и защиты рекламы. Отключение персонализации не означает отсутствия обработки технических данных. В подготовленной интеграции передаётся отсутствие согласия на персонализацию и отключено отслеживание местоположения средствами рекламного SDK.

Обработка данных Яндексом регулируется его [политикой конфиденциальности](https://yandex.ru/legal/confidential/); сведения о категориях данных SDK опубликованы в [документации Yandex Mobile Ads](https://ads.yandex.com/helpcenter/ru/easy/integration/android/advanced-settings/security-privacy).


## Оценки RuStore
Android-приложение может предложить оставить оценку через RuStore Review SDK. Оценка необязательна, не влияет на доступ к уровням и не приносит игровых наград. При использовании функции данные аккаунта и отзыва обрабатываются сервисом RuStore по его [политике конфиденциальности](https://www.rustore.ru/help/legal/privacy). Разработчик игры не запрашивает пароль от аккаунта RuStore.


## Обращения и удаление данных
При добровольном обращении в поддержку разработчик получает текст обращения, приложенные вами сведения и публичное имя аккаунта GitHub. Они используются для ответа и устранения проблемы. Хранение обращений на GitHub регулируется правилами этой платформы. Через тот же канал можно запросить информацию об обработке переданных разработчику данных, их исправление или удаление. Не публикуйте в обращении данные, которые не нужны для решения вопроса.

Локальный игровой прогресс можно удалить в настройках браузера или Android, очистив данные сайта или приложения. Разработчик не может восстановить эти сохранения. Сроки хранения технических данных GitHub и RuStore определяются политиками соответствующих сервисов.


## Изменения политики
Актуальная редакция публикуется на этой странице с датой обновления. Если состав данных или подключённых сервисов изменится, описание будет обновлено до выпуска соответствующей версии игры.
