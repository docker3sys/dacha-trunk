# Карточка игры для RuStore

Текст для первой release-версии 1.0.0 с отключённой рекламой (`YANDEX_ADS_DISABLED=true`). Перед отправкой сверить скриншоты с итоговым APK.

**Название:** Багажник на дачу

**Краткое описание:** Уложи вещи в багажник: уютная головоломка о поездках на дачу.

**Категории:** Головоломки; Казуальные — выбрать соответствующие варианты в Консоли.

**Полное описание:**

Чемодан, рассада и вещи для отдыха уже у машины. Осталось самое интересное — найти место для каждой вещи!

«Багажник на дачу» — спокойная головоломка на пространственное мышление. Перемещайте предметы, поворачивайте их и пробуйте разные варианты укладки. Каждый багажник устроен немного по-своему, а привычные вещи порой оказываются совсем непростыми соседями.

В первой версии:

- 30 уровней в трёх главах;
- разные формы багажников и наборы предметов;
- короткие игровые сессии;
- отмена действий и повторные попытки;
- сохранение прогресса на устройстве;
- подсказки, когда нужна помощь;
- четыре цвета машины: открывайте их за монеты, заработанные в игре.

Головоломки можно проходить без интернета. В первом выпуске нет рекламы и покупок за реальные деньги: подсказки и бонусы доступны бесплатно. Для игры не нужен аккаунт.

Соберите всё необходимое — и в дорогу!

**Что нового в 1.0.0:**

Первый выпуск: 30 головоломок, три главы, четыре цвета машины, поворот и укладка предметов, сохранение прогресса и бесплатные подсказки.

**Контакт разработчика:** https://github.com/docker3sys/dacha-trunk/issues

**Сайт игры:** https://docker3sys.github.io/dacha-trunk/

**Политика конфиденциальности:** https://docker3sys.github.io/dacha-trunk/public/privacy.html

## Материалы и поля, которые заполняются по сборке

- Иконка: `public/icon-512.png`, PNG 512×512.
- Три скриншота: первый уровень, более сложный багажник и экран выбора уровней. Использовать реальные кадры интерфейса без обещаний дохода, рейтингов или неподтверждённых наград.
- Возрастная категория: определить по анкете RuStore и используемому рекламному содержимому; предварительно не назначается автоматически.
- Встроенная реклама: в первом выпуске отключена. Если анкета отдельно спрашивает о включённых SDK, отразить наличие Yandex Mobile Ads и его зависимостей даже при отключённых показах.
- Встроенные покупки: в первой версии не реализованы.
- Политика конфиденциальности: доступна по ссылке выше; владелец — Соболь Александр, контакт — GitHub Issues.
- Комментарий модератору: регистрация в игре не нужна. Игра работает офлайн; в сборке 1.0.0 реклама отключена, бонусы бесплатные. SDK отзывов RuStore используется для необязательной оценки; за отзыв награды не выдаются.

В эту версию не включены ежедневные задания, сетевые рейтинги, облачные сохранения и сюжетное событие с дополнительной вещью после завершения уровня. Не добавлять эти функции в описание до реализации.
